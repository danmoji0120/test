## 실패·수정 이력

- 이전 조종기는 발전기 방호를 무시하고 정면 사격하거나 새 시설 충돌을 경로 단축에서 무시했습니다. 실제 시설 clearance·A* 다중 접근·조종 경로 검사를 일치시켰습니다.
- `browser/tuning-four-input-stall`은 느린4창 DOM 샘플링으로 모서리 이동이 진동하여 중단한 QA입니다. 인게임 패배/성공으로 집계하지 않았습니다. 실제 입력을 짧게 탭하도록 조종기만 수정한 뒤 `verified-4`가 성공했습니다.
- 동시 브라우저/CPU 작업 중100 Seed 검사·worker RPC가 벽시계 제한을 넘었습니다. `tuning/co-load-timeouts`에 실패 로그를 남겼고, 검사 수나 조건을 줄이지 않고 분리 실행했습니다.
- 네트워크 소비 검사는 고정400ms 대기 대신 서버가 실제 전환 완료를 알린 후 입력하도록 수정했습니다. 장비 전환 도중 누른 소모품이 자동으로 사용되지 않는 정상 latch 규칙을 테스트가 어기지 않게 한 변경입니다.

## 반복·오디오·시각 검사

24회 혼합 장비/네 인원 반복은 성공20/실패4/미완료0입니다. GC후 heap 표본은10.76→11.63→11.98→11.53→11.50→11.51MiB, 이벤트 최대160/적 최대50,샘플 틱 p954.77ms였습니다. 이 길이의 시험에서 지속 증가를 관찰하지 않았지만 수시간 브라우저 네이티브/GPU 메모리 누수까지 부정하는 증거는 아닙니다. `stability/stability-qa.json`에24개의 결과를 보존했습니다.

`final-visual-audio/audio-qa.json`과15WAV는 실제 AudioEngine을 Chromium OfflineAudioContext로 렌더한 것입니다. 클리핑0이며 파형/감쇠를 측정했습니다. 전문적인 청음 품질·총격의 재미를 사람 없이 인증하지 않습니다. 720p/1080p 로비·선택·AT/권총/네 소모품·교전·추출·성공/실패 이미지를 직접 검토했습니다. 720p 세 장비 슬롯은 화면 안에 들어가며 전체 페이지는818px여서 초상화 하단/푸터는 스크롤됩니다.

## 알려진 한계와 미완료 평가

- 실제 사람이 한 플레이 재미·조준 감각·사운드 청음·숙련도별 최고 난이도 승률은 미검증입니다. 난이도10 솔로15조합의 실패를 인간 승률로 바꾸지 않습니다.
- 자동 조종기는 전체 정적 지도/목표를 알고 보이는 적을 자동 조준합니다. 일반 작전 성공90–135초는 목표8분 이상 페이싱을 검증하지 않습니다. 사람의 정보 제한과 플레이 시간을 평가해야 합니다.
- Windows 실제GPU와 서로 다른 장치 LAN/WAN은 미검증입니다.60FPS와64명 과부하30Hz 목표는 미달입니다. 큰 시야/지형 갱신의 네트워크 비용도 남아 있습니다.
- 기존 본체 PNG에 무기 이미지를 합성 표시하므로 일부 기본 총기 포즈가 남습니다. 독립 리깅이나 픽셀 단위 부위 판정이 아닙니다. 소모품 투척은 벽을 넘어가는3D 탄도가 아니라 실제2D 충돌입니다.
- 모든 주무장의 낮은 난이도 솔로 성공과100 Seed 약점 접근 가능성은 확인했지만 모든 난이도에서 모든 무장의 사람 솔로 승리를 검증하지 않았습니다.
- `tuning`,이전`operations/final-operations/loadout-tuning`,이전 브라우저 기록은 수정 전 이력입니다. 최종123사례는 위 네 디렉터리와 `final/summary.json`만 집계합니다. 정상 입력/조건을 바꿔 성공률을 맞추지 않았습니다.

## 재현

기본은 `npm install && npm run build && npm test`입니다. 브라우저에는 Chromium/Playwright가 필요합니다. 셸 환경변수 문법은 OS에 맞게 바꿉니다.

```sh
QA_REPORT_DIR=docs/v4.1/recheck QA_MAX_SECONDS=360 npm run qa:v41
QA_OUTPUT=docs/v4.1/recheck-combat npx tsx scripts/v41-combat-qa.ts
QA_REPORT_DIR=docs/v4.1/recheck-stability node --expose-gc --import tsx scripts/v41-stability-qa.ts
QA_OUTPUT=docs/v4.1/recheck-browser QA_PLAYERS=4 QA_DIFFICULTY=1 QA_SEED=42 QA_LOADOUTS=ar/antiarmor,smg/smoke,sg/medical,at/frag npx tsx scripts/qa-session.ts
npx tsx scripts/v41-performance-suite.ts
node scripts/v41-report.mjs
```

최종 명령은 저장된 원본을 집계할 뿐 시험을 새로 실행하지 않습니다. 무작위18/장비30/후방6사례의 환경은 각각 `QA_SEEDS=837261`, `QA_COMBOS=1 QA_LEVELS=1,10 QA_COUNTS=1 QA_EXTRA=0`, `QA_MODE=tactical QA_LEVELS=10 QA_COUNTS=1,4 QA_EXTRA=0`이며 공통 최대360초입니다. 성능·회귀·브라우저는2CPU 자원을 공유하므로 순차 실행합니다.
