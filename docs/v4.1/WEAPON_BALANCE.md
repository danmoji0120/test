# V4.1 무기·난이도 밸런스

수치의 원본은 `src/shared/data.ts`와 `src/shared/difficulty.ts`입니다. 일반 보병의 HP는 V4와 동일합니다(소총65/돌격48/지원105). 난이도별 HP 배율은 없습니다.

SMG는 이동 탄퍼짐0.009·이동속도1.04, AR은0.027·1.0입니다. SG는 개별 산탄의 실제 명중만 합산하며, 근접을 벗어나면 탄퍼짐/감쇠가 함께 커집니다. AT는 이동 탄퍼짐0.1·속도0.94·긴 장착/장전을 감수합니다. 대전차 수류탄의235거리는 AT1050보다 훨씬 짧아 접근 위험이 있습니다. 보급이나 크레딧 특전과 발사기를 같은 슬롯에 넣지 않습니다.

## 통제 실험

[측정 코드](../../scripts/v41-combat-qa.ts)는 고정 Seed42/정지 표적에 실제 광선·탄체를 발사하고 탄창/예비탄/장전/30Hz 발사 간격을 적용합니다. 적은 움직이거나 반격하지 않는 fixture입니다. 사람의 TTK·실전 승률이 아닙니다. 전체 결과는 `final-combat/combat-experiments.json`에 저장합니다.

## 난이도1–10

기존 주둔 밀도·순찰·구성·정예·실제 출동 대응을 보존하고, 새 장갑/무기 책임·사격 통제·시설 방호와 결합했습니다.1–3은 낮은 초기 병력/느린 반응/짧은 경비 활동 반경,4–6은 중장갑 진압병과 분대 대응,7–8은 드론·정예·보행병기,9–10은 공성 지원과 최고 대응의 조합입니다. 각 시설의 경비1명은 추격 때문에 시설을 완전히 비우지 않습니다.

입력 자동화로 성공한 것을 인간의 제한된 정찰·승률·재미 검증으로 간주하지 않습니다. 자동 조종은 공개된 정적 지형을 완전히 알고, 보이는 적을 자동 조준하며, 전술 후방 접근 실험은 공개된 시설 방향을 사용합니다. 무계획 솔로와 준비된 협동/후방 접근의 실패도 모두 기록합니다. 최고 난이도의 인간 난이도 교정과 재미 평가는 아직 필요합니다.
