# V4.1 전투 규칙

V4의30Hz 서버 권한,15Hz 필터된 상태 전송,1–4인 방/로비/재접속/저장/시야와 실제 출발지·경로 기반 증원을 유지합니다. 변경은 장비 선택과 실제 교전 판정에 집중합니다.

## 정확히 세 슬롯

| 슬롯 | 선택 | 조작 |
|---|---|---|
|1 주무장|AR / SMG / SG / AT 중 하나|1, 좌클릭, R|
|2 부무장|P-01 권총|2, 좌클릭, R|
|3 소모품|파편/대전차/연막/의료 중 하나|3, 새 좌클릭|

AT와 AR은 함께 소지할 수 없습니다. G의 기존 즉시 발사는 제거됐습니다. AT는1발 탄창+예비3발,3.4초 장전,0.65초 장착입니다. 권총은12+84발. 주무장별 탄창·예비탄·쿨다운·반동은 별도 상태입니다. 장비 전환은 사격을 막으며, 홀스터한 무기의 장전은 **취소되어 처음부터 다시** 해야 합니다. 장전 이전 탄약은 그대로 남습니다. 쿨다운과 반동 회복은 홀스터 중에도 진행합니다. 출격마다 탄약이 초기화되며, 작전 중 재접속은 기존 서버 상태를 복원합니다.

`Player.guns.primary/secondary`가 독립적인 상태이고, 기존 flat `weapon/ammo/reserve/reload`는 현재 장착 무기를 표시하는 호환 필드입니다. 클라이언트가 이를 지정할 수 없습니다. `activeSlot`, `switching`, `useTime`, `consumableCount`도 서버가 관리합니다.

## 소모품과 보급

|종류|수량|준비|거리/범위|효과|
|---|---:|---:|---|---|
|파편|3|0.3초|430/130|145 일반·18 내구, AP1|
|대전차|2|0.5초|235/75|320 일반·300 내구, AP4|
|연막|2|0.3초|410/145|14초, 양측 관측 차단|
|의료|2|1.2초|자기 자신|체력+65, 최대100|

투척물은 실제 월드 위치에서 이동하고 지형·시설·적에 부딪히며 멈춘 뒤 폭발/발연합니다. 높은 호를 그려 벽을 넘어가는 물리는 없습니다. 우클릭은 예상 착지점·효과 범위를 보여주며, 숨겨진 동적 대상과 충돌하면 실제 착지점은 달라질 수 있습니다. 연막은 AI 관측과 분대 공유 Fog 모두에 적용되고 총탄은 통과합니다. 마지막 시각 정보·소리·무전은 남지만 현재 위치를 갱신하지 않습니다. 연막은 청각을 벽처럼 반감시키지 않습니다. 실제 벽의 소리 감쇠는 유지합니다.

한 번의 클릭은 하나의 사용 준비만 시작합니다. 누른 채 기다려도 추가 소비하지 않으며, 전환/쿨다운 중 누른 버튼도 다시 떼었다 눌러야 합니다. 질주·상호작용·소생·쓰러짐·연결 종료는 준비를 취소합니다. 의료품은 만피에 소비하지 않습니다. 발사체 상한96에서 실행되지 못한 장비는 소비하지 않습니다.

각 맵 보급 상자는 팀 공용1회입니다. 주변200거리의 생존자에게 체력 회복, 소유한 주/부무장 예비탄50%(AT 최소1발), 선택 소모품1개를 제공합니다. 최대 예비탄·휴대량을 넘지 않습니다. AT가 없는 대원에게 별도 로켓 인벤토리는 생성되지 않습니다. V4의 안전 회복(피격 이후4초가 지나면45HP까지3HP/s)은 유지하므로, 의료품은 안전 회복 상한을 넘어 빠르게 복구합니다.

## 사격 통제와 분대

`aim-controller.ts`는 연속 **실제 목격 좌표**로만 속도를 추정합니다. 플레이어 입력값/숨겨진 실시간 좌표를 읽지 않습니다. 목표 획득·제한된 조준 회전·정확하지 않은 이동 예측·반동/탄퍼짐이 있습니다. 보행병기 주포와 몸체는 별도 회전하며, 기본 주포1.15rad/s·몸체0.7rad/s입니다. 상실한 목표는 마지막 정보로만 수색합니다. 포격은 여전히 날짜가 있는 시각 보고와 고정 착탄점·2.6초 경고를 요구합니다.

Assault는 압박, Suppress는 실제 사선 유지, Flank는 측면 경로, Intercept는 최근 관측 속도로 퇴로 접근, Guard는 시설 근처 방어를 맡습니다. 각 주요 장소의 첫 경비는 Guard로 유지합니다. 아군 시설도 적탄을 막으며, 막힌 사수는 실제 이동 가능한 옆 사선을 찾습니다. 경로·충돌·시야·기억 정보가 기존 물리적 전장 규칙을 따릅니다.

## 저장과 보안

저장 형식1과2를 읽고2로 기록합니다. 기존 토큰/크레딧/무기·개조 해금/승패/처치/정산 기록과 기타 기존 메타데이터를 보존합니다. 기존 주무장은 유지하며 `tactical:launcher|ammo` 때문에 AT로 바꾸지 않습니다. 기본 부무장과 소모품을 추가하고, 선택 로드아웃과 오퍼레이터는 프로필에 저장합니다. 잘못된 로드아웃 요청은 캐릭터까지 부분 변경하지 않고 거부합니다. AT와 권총은 기본 해금입니다. SG 기존 구매 조건은 유지합니다. 원자적 임시 파일·백업 복원·중복 보상 방지도 유지합니다.

서버는 슬롯·ID·해금·입력·탄약·소모품·피해·부품·목표·보상을 검증합니다. 위치/피해/탄약을 클라이언트가 보내도 반영하지 않습니다. 부위 상태와 포탑 방향은 현재 보이는 적에게만 전송합니다. 숨겨진 적·탄체의 좌표 필터는 기존대로 유지됩니다.
