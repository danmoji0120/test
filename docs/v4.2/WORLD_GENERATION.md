# V4.2 미션 기반 생성

입력은 Seed·미션·난이도·플레이어 수·프로파일·생성 버전42입니다. Mission Graph 검증 → 공간 예산과 시설 역할 → 전략적 장소 표본 배치 → 도로 MST와 우회 연결 → 황무지 능선/암석/지형장 → 시설 문법 → 목표/실제 출발지/순찰/보급 → 투입·탈출·작업 위치·대형 경로 검증 순서로 생성합니다.

| 프로파일 | 크기       | 지원 작전                     |
| -------- | ---------- | ----------------------------- |
| compact  | 3200×2400  | 시설 방어                     |
| standard | 6400×4200  | 신속 파괴, 원자로             |
| large    | 9600×6300  | 전략 발사, 원자로, 운반, 조사 |
| expanded | 12800×8400 | 전략 발사, 원자로, 운반, 조사 |

총11개 조합입니다. 방어를 거대한 이동 작전으로 바꾸거나 신속 파괴에 장거리 이동을 강제하지 않도록 나머지 조합은 정의·서버에서 거부합니다. 크기는 난이도와 동의어가 아닙니다. 방장이 로비에서 크기와 공개된 목표 추정 지역·공동 투입 세 곳·탈출 후보를 확인합니다.

Seed마다 장소 상대 위치, 도로 연결, 입구 방향, 시설 벽의 반전/구조, 암반/우회 경로, 실제 출발지와 경비가 변합니다. 발사대·원자로·드릴·전송기·통신탑·분석기·방어 시설은 역할별 물리 구조와 작동 연출을 가집니다. 대형 암석은 실제 이동·사격·시야를 차단하고 낮은 엄폐는 기존 규칙을 따릅니다. 장식 PNG는 충돌 바위와 별도입니다.

목표 시설 외에 크기별2/4/8개 POI를 추가합니다. 보급·정보·물리 출동 능력 등 실제 효과가 있습니다. 조경만 있는 아이콘을 목표로 계산하지 않습니다. 숨겨진 POI는 발견 전 이름·정확한 위치를 전송하지 않습니다.

투입은 방장 공통 선택입니다. 네 명의 실제 출현 대형, 세 투입 지점 모두의 목표 경로, 실제 작업 지점, 모든 탈출 후보, 반경56 중장비가 모든 시설 입구·출발지·투입·탈출에 접근 가능한지를 검사합니다. 출발지 안쪽에서 실제 문/출입구까지도 연결되어야 합니다. 입구를 바꾸기만 했을 때 지형 전체가 재생성되지 않도록 세 투입 선택을 공통 검증한 뒤 실제 spawn만 고릅니다.

실제 충돌 경로를 사용한 선행 순서 준수 기준 동선을 계산합니다. 기본 이동속도280기준 순수 이동량이 신속90초·방어60초·나머지180초를 넘으면 재배치합니다. 이는 전투·탐색을 포함한 인간 플레이 길이가 아닙니다. 최대3번 결정론적 시도 후 명확한 생성 오류를 반환하며, 장애물을 몰래 지워 통과시키거나 무한 재시도하지 않습니다. 로비에 오류를 표시하고 출격을 거부합니다.

전체 Seed 검증 결과와 실패를 수정한 기록은 [QA_RESULTS](QA_RESULTS.md)에 연결합니다. 초기3300검사에서 정확한 두 중장비 입구가 막힌 사례를 발견했고 검증·재시도 규칙을 강화했습니다. 실패 원본은 tuning에 보존했습니다.
