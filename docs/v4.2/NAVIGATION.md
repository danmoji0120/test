# 경로·원거리 이동·공간 검색

50월드 단위 상세 격자를 유지하면서 기존 선형 정렬 탐색을 안정된 우선순위 힙으로 바꿨습니다. 동일 점수는 기존 FIFO 순서를 유지해 V4.1 적 이동 회귀를 줄입니다. 충돌 셀은 반경별로 필요할 때 계산하고, 상세 경로는 최대128개 LRU로 재사용합니다. 새 작전은 실제 출발점에서 첫 격자 중심까지의 연결과 모든 인접 이동 구간을 검증합니다.

반경은 보수적으로4단위 올림하며, 반경별 양방향 간선의 유효성도 비트 마스크로 캐시합니다. 문/시설의 충돌 상태가 바뀌면 관련 캐시를 무효화합니다. 중장비 입구는 반경56 실제 공간으로 검증합니다. 전체 생성 검증은 연결 컴포넌트 BFS를 사용해 많은 출동지·작업 위치를 중복 A* 없이 확인합니다. 지역 도로 그래프는 배치·동선 검증에 사용하며, 런타임 AI의 최종 상세 경로는 여전히 격자 A*입니다. 완전한 계층형 내비게이션/증분 최단 경로 엔진을 구현했다고 주장하지 않습니다.

장애물은256단위 공간 해시로 광선·시야·이동 후보를 제한합니다. 문 상태는 후보 안에서 실시간 판정합니다. 배열 교체/구조 변화에는 인덱스를 무효화합니다. 동적 개체는 현재 병력 상한과 실제 후보 수를 고려해 기존 배열 검사를 유지하는 부분이 있습니다. 모든 검색이 공간 분할됐다는 뜻은 아닙니다.

V4의 원거리 저빈도 전략 이동과 지역/교전/이동 병력 예산을 보존합니다. 적은 실제 분대·출동지·경로·좌표·목격 정보로 이동하며 거리에 따라 사라지거나 텔레포트하지 않습니다. 긴 작전의 먼 출발지는 실제로 늦게 도착합니다. 주변 주둔군과 사이트별 출발지를 먼저 대응시킵니다. 병영 파괴 후 이미 출동한 병력은 계속 이동합니다.

회귀 테스트는 반경별 유효 경로·경로 재사용·문 상태 변경·막힌 정확한 입구·투입 선택과 지형 재현성을 검사합니다. `navigationStats(map)`은 쿼리/히트/방문 셀/캐시 수/격자·간선 메모리를 제공하며 성능 fixture에서 별도로 기록합니다. 입력 작전 QA는 모든 실제 증원 궤적의 출발지·요청 경로·이동 속도 연속성을 검사합니다.
