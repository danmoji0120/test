# 재미 중심 전투 개편

## 유지 / 교체

| 유지한 기반                                | 갈아엎은 부분                           |
| ------------------------------------------ | --------------------------------------- |
| Node 서버 권한형 이동·피해·보상, WebSocket | 무기 피해·간격·이동 퍼짐·장전·타격 연출 |
| 방 코드·로비·준비·방장·재접속              | 두 중계기+설치+300초 방어 상태 머신     |
| 크레딧·해금·개조·익명 프로필 저장          | 고정 벽과 소품만 달라지던 맵 생성       |
| Vitest·Playwright·입력 파일럿              | SVG 캐릭터 본체와 초상화                |
| 캐릭터 2종·무기 3종·적 3종                 | 적의 이동·발사 빈도·측면 압박           |

## 총격

AR은 근거리 두 발 처치와 중거리 점사, SMG는 이동 연사와 빠른 장전, SG는 균등한 10개 산탄과 근거리 경직을 강조합니다. 섬광의 크기·저음·노이즈 필터·화면 반동이 달라졌습니다. 명중 수치, 처치 확인음과 마커, 바닥 잔해, 장전 진행 원을 추가했습니다. SG가 산탄별로 발사음을 10번 재생하는 문제를 없애고 한 발사당 한 번만 연출합니다.

마우스를 누른 프레임에 발사 연출을 시작합니다. 서버가 탄약/피해/처치를 계속 판단하며 확인 이벤트를 받아 로컬 연출의 중복을 줄입니다. 피해·명중을 미리 확정하지 않습니다.

## 템포와 임무

이동 205→280, 조준 배율 .62→.82. 빈 상호작용 시간을 제거했습니다. 새 흐름은 침투→9개 구역 전진 돌파→발전 장치 2기를 사격해 파괴→60초 붕괴 위기 속 탈출입니다. 추출 원 3초 조건을 채우면 바로 귀환합니다. 300초 방어는 존재하지 않습니다.

구역마다 2~3회의 짧은 교전이 이어집니다. 보급을 경로상에 두고 자료는 선택 목표로 유지했습니다. 목표 장치를 사격할 때도 일반 총격의 탄약과 엄폐 판정을 사용합니다.

## 맵과 위험

2400×1800의 고정 벽 대신 4000×2700의 12개 산업 모듈을 조합합니다. 야적장/창고/회랑/보안실/발전실/추출 구역, 구역별 벽·소품 템플릿, 가로·세로 진행과 역순이 Seed에 따라 달라집니다. 경계마다 두 출입구를 두어 우회와 측면 진입이 가능합니다. 길만 늘리는 방식은 피하고 중간 엄폐와 교전 편성을 구역에 밀집시켰습니다.

적 HP는 65/48/105를 유지합니다. 소총병은 횡이동하고, 돌격병은 빠르게 파고들며, 지원 사수는 예고 후 고정 각도의 3연발로 통로를 압박합니다. 피격 경직은 사격으로 위협을 끊는 역할을 합니다.

## 아트

공식 아리아 PNG를 로비/선택/HUD/결과에 사용합니다. 같은 PNG를 실제 imagegen 참조로 넣어 아리아/루나 4방향 래스터 시트를 생성했습니다. 월드 캐릭터를 코드 도형이나 SVG 머리 조합으로 표시하지 않습니다. 시트의 불균등한 여백은 실제 알파 영역을 측정해 프레임 좌표로 보정했습니다.

## 판단의 범위

실제 입력·총격·타격 연출·협동 흐름·스크린샷을 검증했습니다. 자동 파일럿은 정밀한 관찰을 이용하므로 사람의 재미를 증명하지 않습니다. 8–10분은 사람 분대의 목표이며 실측과 달성 여부는 QA에 그대로 기록합니다. 콘텐츠 확장으로 미검증된 재미 문제를 숨기지 않습니다.
