# Phase 5 — independent objectives and extraction

Removed `Mission.checkpoint`, linear encounters, clearance gates, the single V2 core/extract position and meltdown timer. Both generators accept damage from insertion in either order. Comms/outposts affect real dispatch sources; intel is a three-second E interaction. Main completion enables an explicit request at any candidate, a 24-second transport approach, visible landing and three-second all-connected-player boarding. Combat and dispatch continue throughout. Rewards emphasize objectives and cap the entire kill bonus at 40 credits.

Build and 64 tests passed (`phase5-build.txt`, `phase5-tests.txt`). Unit/input tests include reversed main order without clearing the garrison, all auxiliary objectives, communications cancellation, physical patrol activity after main completion and landed-only boarding.

Actual four-Chromium DOM-input test, Seed 42, reached both generators and requested extraction at 271.7 simulation seconds. Reconnect and combat revivals worked. The first geometry trial exposed an interior navigation trap; prefab clearances and 20-seed corner regression tests fix it. An early combat failure remains recorded under `tuning/phase5-combat`, rather than being omitted. The next trial reached extraction but exposed QA pilot rally/boarding oscillation under four-browser CPU contention; the pilot now stops rallying toward the leader during extraction and approaches the boarding zone at walking speed. Final V3 end-to-end results supersede this intermediate trial, without treating automatic control as evidence of human enjoyment.
