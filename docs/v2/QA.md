# PROJECT DOLL SQUAD V2 — 실행·시각·협동 QA

검증: 2026-10-15 KST. V2 원시 기록은 `docs/v2/`, 실제 캡처는 `docs/v2/after/`, V1 비교는 `docs/v2/before/`입니다. 이전 V1 QA 문서를 `docs/v2/before/QA-v1.md`에 보존했습니다. 실행 성공과 자동 조종, 실제 사람의 재미·청음 평가는 구분합니다.

## 환경과 재현

Linux x86_64, Node24.19.0, Chromium154.0.8037.57, AMD EPYC9V74 가상머신의 vCPU3 / RAM 약9.7GiB. 한 머신에서 네 격리된 브라우저 컨텍스트와 서버를 실행했습니다. Windows/GPU 실기, 다른 PC LAN, WAN/공용 배포는 검증하지 않았습니다.

```sh
npm install
npm run dev
npm run build
npm test
# 실행 중 서버 대상으로 실제 DOM 입력 검증
QA_URL=http://localhost:3000 QA_SEED=7 QA_MIXED=1 QA_OUTPUT=docs/v2/after QA_REPORT_DIR=docs/v2 npm run qa
QA_REPORT_DIR=docs/v2 npm run qa:sim
QA_REPORT_DIR=docs/v2 npm run qa:stability
```

최종 전체 검증은 프로덕션 번들을 `npm run qa:session`으로 QA와 함께 실행했습니다. 분리해 띄운 서버 프로세스가 도구 환경에서 종료된 중단 실행은 성공/실패 집계에 넣지 않았습니다. 게임에 재시작 복원 기능을 추가한 것은 아닙니다.

PowerShell에서는 `$env:QA_URL="http://localhost:3000"`처럼 환경변수를 설정합니다. Chromium 위치는 `CHROMIUM_PATH`로 지정합니다. `qa:render`와 `scripts/audio-qa.ts`는 Vite 개발 서버에서 실행해야 합니다.

두 번째 실행은275.8초/138처치,14회 소생 후 네 명이 살아서 추출 구역에 도착했지만 파일럿의 회피 동작이3초 집결을 반복해서 끊어 기한 초과했습니다. `docs/v2/tuning/extraction-dodge-failure.json`/PNG에 보존했습니다. 게임의 기한·집결 판정은 변경하지 않고 파일럿만 추출 안에서 회피를 멈추도록 수정했습니다.

1·2인 실제 브라우저 스모크: 각각9처치와26처치, 두 클라이언트 작전 ID 일치, 브라우저 오류0(`docs/v2/smoke-qa.json`). 다른 네 브라우저 검증과 함께 실행돼30초 벽시계 동안 게임 시간22.2/25.4초였습니다. 전체 성공이나 독립 성능으로 주장하지 않습니다. 이 동시 부하의4인 실행은 평균 프레임114.9ms로 초반 전멸했고 `tuning/parallel-browser-failure.json`에 보존했습니다. 최종4인 검증과 별도 렌더 부하 검증은 다른 브라우저 작업을 종료한 뒤 수행합니다.

## 성능

실제4개 컨텍스트를 같은3-vCPU 머신에서 실행한1번 화면:570샘플,평균43.05ms(약23.2FPS),중앙값33.6/p95 92.8ms. 마지막15초가량 빌드·Node 자동 검사도 함께 실행된 결과이며 일반 Windows/GPU나 각자 PC의 성능으로 확대하지 않습니다. 수치가60FPS 목표에 못 미치는 환경임을 명시합니다.

**별도1920×1080/아군4·적20 합성 렌더:600샘플,평균16.694ms(약59.9FPS),중앙값16.7/p95 17.0ms.** 결과는 `docs/v2/render-qa.json`. 모든 적을 실제로 표시하도록 장애물 없는 별도 스트레스 장면을 사용하며 다른 브라우저 검증은 종료한 뒤 측정합니다. 캡처는 `docs/v2/performance/render-benchmark.png`이고 **실제 작전 화면이 아닙니다**.

## 시각 검토

[전후 실제 화면](docs/v2/COMPARISON.md). 720p/1080p 로비, 선택, 네 명 편성, 실제 교전·사격·장전·피격, 단계 전환과 결과를 캡처합니다. 시트64의 아군은 밝은 머리카락으로 식별되고, 적은 밀폐 헬멧/적색 바이저/올리브·적갈·황토 장비로 구분됩니다. 기존 같은 크기의 방 대신 큰 시야 차단물과 좁고 꺾이는 통로가 보입니다. 교전 캡처에는 실제 체력 감소와 장전 링·섬광·예고선이 있으며 가짜 렌더나 이미지 생성 전투 화면이 아닙니다.

`assets/enemies-atlas.png`는 **실제 imagegen 호출 결과**,1448×1086 RGBA, 알파0~255. 측정한12개 포즈 프레임을 사용하고 원본PNG를 변형하지 않았습니다. 기존 도형 적 몸체는 제거했습니다. SVG/Canvas는 환경·HUD·이펙트에만 사용합니다.

## 음향 출력 검증

`npx tsx scripts/audio-qa.ts`: 같은 실제 `AudioEngine`을 Chromium `OfflineAudioContext`로 합성한48kHz PCM WAV를 `docs/v2/audio/`에 저장했습니다. 코드의 대체 사운드가 아닙니다. 각 무기 첫100ms RMS는 AR .0112 / SMG .00425 / SG .0251, .1~.3초 꼬리는 .000239 / .0000061 / .003568, 세 출력 클리핑0입니다. 세 연출의 충격과 지속 길이는 달랐으며 사람의 청음 품질 검증은 아닙니다. 랜덤 노이즈이므로 재실행의 정확한 수치는 달라집니다.

## 알려진 한계

- **사람 분대의 재미와8~10분 템포는 미검증.** 자동 조종 완료를 “총 쏘는 재미 PASS”로 주장하지 않습니다. 맵이 넓고 구조가 바뀌어도 인간 반응/역할 분담의 평가가 필요합니다. 긴 방어 대기를 다시 넣지 않았습니다.
- 솔로 난도는 높습니다. 9회 입력 검증 중 솔로 한 Seed가 실패했습니다. 위험 난도는 피해1.4배이며 이번 전체 브라우저 검증은 보통입니다.
- 래스터는4방향 정적 포즈와 절차적 움직임입니다. 보행 프레임/독립 팔·총기 회전/아군3표정PNG는 없으며 아군의 총기 외형은 공통 소총입니다.
- 무전·엄폐 모서리·우회 역할은 구현됐지만 정교한 분대 지휘/실제 벽 뒤 엿보기 애니메이션/적끼리 분리 충돌은 없습니다. 길목에서 겹칠 수 있습니다. 출현 보강문 연출도 없습니다.
- 시설 크기·위치·복도 연결이 Seed로 변하지만 큰 진행 순서와 구역 종류는 고정된12개 날개 계획입니다. 무한 조합 던전이 아닙니다. 적 숨김은 표시용이며 서버는 공개 상태를 전송합니다.
- 음향은 실제 Web Audio 합성이고 사람 청음 평가는 하지 않았습니다. 전문 녹음 총성이나 벽 재질별 공간 음향이 아닙니다.
- Windows/다른 LAN PC/공용 인터넷 미검증. 서버 권한은 유지하나 이동 예측·롤백·지연 보정이 없어 WAN에서 이동·명중 확인이 늦을 수 있습니다.
- 작전/방은 서버 메모리입니다. 재시작하면 작전은 사라지고 진행도만 복원합니다. JSON 저장은 단일 서버용입니다.
