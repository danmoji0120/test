# DOLL SQUAD V2 — 전술 전투 규칙

## 유지한 기반

TypeScript, Canvas 2D 렌더러, Node 권한형 30Hz 시뮬레이션, WebSocket, 방 코드와 준비/방장 권한, 익명 토큰, 구매·해금·개조, 원자적 저장·백업·실행 ID별 중복 보상 방지, 재접속/방 정리, 테스트 인프라를 재사용합니다. 캐릭터 2명, 무기 3종, 적 3종을 유지합니다.

## 캐릭터

아리아는 `assets/aria-tactical-operator.png`의 분홍 트윈테일·검정 전술복·청록 장신구가 공식 기준이며 원본을 그대로 사용합니다. 이동 +6%. 루나는 은보라 머리·보라 베레모·아이보리 재킷이며 소생 +35%. 실제 imagegen으로 공식 아리아 PNG를 참조해 만든 `operators-atlas.png`의 남/동/북/서 네 포즈를 월드에서 선택하고, 작은 보행 기울임·상하 움직임·반동·피격 밝기·쓰러짐 회전을 적용합니다. 세부 프레임은 `src/art/raster.ts`. 생성 시트의 실제 투명 여백을 측정해 프레임을 정의했습니다.

로비의 아리아 초상화는 공식 원본, 루나는 시트 정면입니다. 선택/HUD/결과에서도 PNG를 사용합니다. 표정 전용 이미지 3종은 현재 래스터 버전에서 제공하지 않으며 부상 결과는 채도를 낮춥니다. 월드에서 총기 외형은 공통 소총 실루엣입니다. 이전 SVG 캐릭터 코드는 제거했습니다.

## 이동·조준·네트워크

기본 280 단위/초, 질주 ×1.42, 조준 ×0.82. 아리아 ×1.06, 안정화 그립 ×0.96. 대각선 정규화, 플레이어 반경 16/적 19, 실제 벽 충돌 및 슬라이딩. 입력은 30Hz, 상태는 15Hz이며 위치를 보간합니다. 아군 시트 표시 높이 64(기존 104), 적 60/중화기 66. 720p 줌 .82 / 1080p .95. 마우스 선행 최대165 + 이동48을 합산195로 제한하고 `1−exp(−dt×6)` 보간합니다. 화면 반동은 AR5/SMG2.3/SG12, 흔들림4/1.7/9로 구분하고 빠르게 복귀합니다. 아군의 시야 밖 벽 뒤 적 본체·사격 예고선은 숨깁니다. 이는 렌더링 가독성 규칙이며 네트워크 비밀 상태나 완전한 안개 시스템은 아닙니다.

클라이언트는 조준 방향과 발사 섬광/소리/반동만 먼저 보여줍니다. 예비 발사 큐는 최대 500ms, 탄약·장전·입력 상태로 제한하며 서버 확인 시 같은 발사 연출을 생략합니다. 서버가 피해와 탄약을 결정합니다. 이동 예측/롤백/명중 지연 보정은 없으므로 WAN 지연에서는 이동·명중 확인이 늦을 수 있습니다.

## 무기

`WEAPONS`의 피해, 간격, 탄창, 예비탄, 장전, 퍼짐, 이동 퍼짐, 반동, 사거리, 관통, 산탄, 음색·색·가격을 데이터로 유지합니다.

| 무기   | 피해/산탄 |  간격 | 탄창/예비 |   장전 | 사거리 | 역할                        |
| ------ | --------: | ----: | --------: | -----: | -----: | --------------------------- |
| AR-01  |      34×1 | .12초 |    30/240 | 1.55초 |    700 | 근거리 2발 처치·중거리 점사 |
| SMG-02 |      24×1 | .06초 |    40/320 | 1.15초 |    430 | 기동 연사·낮은 이동 퍼짐    |
| SG-03  |     14×10 | .78초 |      8/64 | 1.95초 |    340 | 근거리 돌파·큰 순간 충격    |

실제 발사 간격은 30Hz 틱에 양자화됩니다. AR 약 .133초, SMG .067초, SG .8초. 기본+이동+누적 반동에 조준 .48배와 개조 배율을 적용합니다. 산탄은 균등한 콘에 작은 흔들림을 더해 완전히 빈 무작위 산탄을 줄였습니다. 판정은 엄폐와 같은 바닥 평면에서 유지하고, 조준 입력과 화면 탄도를 높이 16의 몸통 위치에 맞춰 투영합니다. 적 원형 피격 반경은 27로 상체 조준을 받아들이며, 각 광선은 가장 가까운 엄폐물/적/활성 장치와 충돌합니다. 산탄은 탄창 한 발만 소모합니다.

AR/SMG는 사거리 55%부터 피해 감소, 최소 .3배. SG는 30%부터 빠르게 감소, 최소 .15배. 장갑 피해 배율은 `1−방어력×(1−관통)`. 아군 오사 없음. 한 산탄 발사의 피격은 대상별 합산해 피드백하고 발사음/섬광/탄피는 한 번만 발생합니다. 적 피격 경직은 AR .08초/SMG .035초/SG .22초로 공격/이동을 잠시 끊습니다.

무기별 필터 노이즈의 발사 충격(.14/.075/.24초), 저음82/115/58Hz, 고역 순간 충격과 .18초 스테레오 convolution 잔향. 합산음을 compressor로 제한합니다. 음악적인 피격/처치 음 대신 금속성 노이즈와 낮은 충격, SG 작동 소리, 세 단계 장전음을 사용합니다. 타격 수치·확인 마커·처치 마커/확인음·파편·짧은 잔해, 섬광의 주변 빛, 무기별 제한된 화면 흔들림을 제공합니다. AudioContext는 입력 뒤 활성화됩니다.

## 적 압박과 이미지

`assets/enemies-atlas.png`는 실제 imagegen의 투명 RGBA PNG입니다. 소총병(올리브/밀폐 헬멧), 돌격병(적갈색/전진 자세), 지원사수(황토 장갑/탄띠/중화기)의 남·동·북·서 12개 포즈. 실제 알파 영역을 측정해 자릅니다. 아군의 머리카락·밝은 얼굴과 구분되는 밀폐 장갑 실루엣이며 기본 몸체를 Canvas 도형으로 대체하지 않습니다.

| 적       |  HP | 이동 | 피해 | 사거리 | 준비 / 재대기                      |
| -------- | --: | ---: | ---: | -----: | ---------------------------------- |
| 소총병   |  65 |  170 |   11 |    580 | .20초 / .90초                      |
| 돌격병   |  48 |  235 |   14 |    220 | .16초 / .70초                      |
| 지원사수 | 105 |  125 |  9×3 |    660 | .55초 뒤 .14초 간격 3연발 / 1.50초 |

760 안의 벽 차단 시야로 대상을 선택하며 첫 발견 시 대기시간을 없애 즉시 사격 준비를 시작합니다. 발사 방향은 준비 시작 때 잠그므로 옆으로 회피할 수 있습니다. 적 사격 퍼짐은 ±.08rad이며 가만히 있어도 항상 명중하지는 않습니다. 가까운 620 범위 적에게 마지막 목격 **좌표의 사본**을 1.6초 간격으로 전파하고 최대8초 기억합니다. 전달 때 기억을 짧게 차감해 관찰 없는 무전만으로 기억이 무한 갱신되지 않습니다. 주변 620 내 총성도 4초의 위치 정보를 줍니다. 보이지 않는 플레이어의 실시간 좌표를 추적하지 않습니다.

지원사수는 anchor, 나머지 40%는 flank, 나머지는 assault 역할입니다. flank는 마지막 목격 위치 옆100~260의 통과 가능한 목표를 골라 A*로 우회합니다. 소총병과 지원사수는 가까운 고체 엄폐 모서리의 사격 가능한 위치로 이동하고, 지원사수는 사거리 내 통로를 유지합니다. 근접 시 비돌격병은 물러나며, 기억이 끝나면 순찰로 돌아갑니다. 가까운 다음 구역 경계대도 현재 구역 완료 전에 활성화될 수 있어 교전이 연결됩니다. A*는 50 단위 격자를 캐시하며 벽을 통과하지 않습니다. 적끼리의 분리 충돌·정교한 엄폐 엿보기 애니메이션은 없습니다.

## BLACKOUT — 전진하는 작전

`Mission.stage`: `infiltrate → breach → destroy → extract → success/failed`.

1. 투입 뒤 전방 두 구역의 경계선을 뚫습니다.
2. 다음 산업 구역들을 순서대로 돌파합니다. 전체 9개 교전 구역. 각 구역은 2~3개 짧은 적 편성을 상대하며 모두 처치하면 즉시 다음 목표를 표시합니다. 버튼을 누르고 고정 시간을 기다리는 목표는 없습니다. 실제 문을 잠그지는 않으므로 다른 출입구/측면을 이용할 수 있습니다.
3. 발전실의 노출 장치 2기(각 240 HP)를 직접 사격해 파괴합니다. 9개 구역 돌파 전에는 장치 피해를 받지 않습니다.
4. 마지막 장치 파괴 즉시 60초 붕괴 경보와 후방 추격을 시작합니다. 추출 구역에 즉시 경계대가 생성되고 후방 추격대는 12초 간격. 전원이 살아서 반경 140 추출 원에서 3초 머물면 즉시 성공하며 60초를 기다릴 필요는 없습니다. 기한을 넘기면 실패합니다.
5. 연결된 전원이 쓰러지거나 14분 제한을 초과해도 실패합니다.

교전 편성은 `3 + 살아 있는 대원 수`명, 추격 편성은 `2+대원 수`명, 전체 동시 적 상한 30. 출현 패드 근처 220 이내에서 플레이어에게 보이는 위치에는 생성하지 않습니다. 기존 표적이 모두 죽은 직후 다음 편성이 생성되므로 실제 보강문 애니메이션/출현 카운트다운은 아직 없습니다.

F 소생은 3초(루나 ×1.35 진행), 최대 빠른 구조자 한 명의 배율만 적용합니다. 소생 후 55 HP. 보급은 한 번만 소비되며 반경 200 분대에게 100 HP와 초기 예비탄의 55%를 보충합니다. 공격을 피하면 최대 45 HP까지 느리게 회복합니다. 기밀 자료는 E로 3초 회수하며 선택 보너스입니다.

## 불규칙 시설 맵

5,000×3,300에서 12개 서로 다른 면적의 시설 날개를 빈 공간으로 파내고, 나머지는 완전히 막힌 구조물로 둡니다. 외곽→보안→창고→설비 복도→후방 창고/보안→중앙 통로→발전실→추출의 진행이며 각 구역 위치±50/크기±100, 꺾이는 복도의 방향과 일부 보조 연결, 장비 배치가 Seed에 따라 달라집니다. 균일한 4×3 방 격자와 네 가지 순회는 제거했습니다. 무제한 그래프 생성은 아니며 큰 진행 순서와 구역 종류는 고정입니다.

주 연결 복도200~250, 서비스 우회로150. 외곽 순환, 중앙 횡단, 발전/추출 우회 등 여러 고리를 만들고 내부에는 큰 컨테이너·설비벽·코너를 배치합니다. 각 구역 중앙의 교차 통로와 목표 공간을 예약합니다. 막힌 바닥 격자는 동일 수평 구간을 세로 병합해 충돌 직사각형 수를 줄입니다. 모든 고체 구조물은 이동·탄도·시야를 차단합니다. 100 Seed의 중심·장치·보급·자료·탈출 경로를 검증합니다. 로비 브리핑과 HUD는 실제 생성 구조를 표시합니다. 다음 출격 Seed +7919.

## 성장·통신

초기 300 CR, SG 220 CR, 개조 각 140 CR. 안정화 그립 반동−30%/이동−4%, 고속 장전기 장전−20%/퍼짐+10%. 성공300/실패60 + 처치4(최대180) + 기밀100. 위험 작전은 피해×1.4/보상×1.3. 보상은 서버가 실행 ID별 일회 정산합니다.

권한 검증·4인 정원·입력 유한성/범위·해금 검사·4KB 패킷·초당100 메시지·1MB 전송 버퍼·250ms 입력 만료·15초 heartbeat 유지. 재접속 유예60초, 방장 승계, 빈 방 정리. JSON+백업 진행도는 유지되며 서버 재시작 시 활성 작전은 복구하지 않습니다.
