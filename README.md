# PROJECT DOLL SQUAD · V0.1

생성 PNG로 표현한 귀여운 전술 오퍼레이터들이 빠르고 위험한 교전을 벌이는 **1–4인 서버 권한형 협동 탑다운 슈터**. 구역을 돌파하며 전진하고 발전 장치를 사격해 파괴한 뒤, 분대 전원이 탈출하세요. 로비·방 코드·저장 구조를 재사용한 전투 개편 버전입니다. 한국어 UI와 절차적 효과음, 포함된 PNG 에셋으로 실행되며 이미지 생성 서비스는 실행 시 필요하지 않습니다.

![분대 준비 화면](docs/after/lobby-1920.png)

## 빠른 시작

Node.js 22 이상과 최신 데스크톱 Chrome / Edge를 권장합니다. Windows에서도 같은 명령을 사용합니다.

```sh
npm install
npm run dev
```

브라우저에서 **http://localhost:3000**을 엽니다. `dev` 명령 하나가 Node 서버와 Vite 클라이언트를 함께 실행합니다. 서버 로직을 편집하면 명령을 다시 실행하세요. 클라이언트는 Vite로 갱신됩니다.

1. 콜사인, 캐릭터와 무기를 선택하고 **새 분대 만들기**를 누릅니다.
2. 혼자 또는 최대 네 명이 **준비하기**를 누릅니다.
3. 분대장이 **출격**을 누릅니다.
4. 노란 목표 구역의 적을 처치하며 전진 → 9개 구역 돌파 → 발전 장치 2기를 **사격**해 파괴 → 붕괴 전 60초 안에 활성화된 추출 원으로 전원 이동 → 3초 후 귀환.
5. 결과 화면에서 크레딧을 받고 **다음 작전 준비**로 반복 출격합니다.

기본 AR-01과 SMG-02는 무료입니다. 초기 300 CR로 SG-03(220 CR) 또는 개조(140 CR)를 해금할 수 있습니다. 구매 후 원하는 무장/개조를 다시 선택하세요. 해금에는 크레딧을 사용하며 현금 결제는 없습니다.

## 빌드·실행·검증

```sh
npm run build
npm start
npm test
```

- `build`: TypeScript 검사, 웹 클라이언트와 Node 서버 번들 생성.
- `start`: 빌드된 `dist/`를 HTTP + WebSocket 단일 포트로 실행.
- `test`: 전투·임무·경로·저장·실제 WebSocket 통합 테스트. 테스트 서버는 3107 포트를 사용합니다.
- `npm run qa`: 이미 실행 중인 개발/프로덕션 서버에서 Playwright 네 브라우저로 실제 전체 작전. 기본 AR-01 편성. 실제 소요 시간은 조준·이동·난도·분대에 따라 달라집니다. 혼합 무장 검증은 `QA_MIXED=1`로 실행합니다. Chromium 실행파일이 필요합니다. Linux 기본 `/usr/bin/chromium`; 다른 환경에서는 `CHROMIUM_PATH` 환경변수로 지정하세요. `QA_URL`로 대상 주소를, `QA_SEED`로 시드를, `QA_OUTPUT`으로 캡처 폴더를 바꿀 수 있습니다.
- `npx tsx scripts/simulation-qa.ts`: 1·2·4인, 세 Seed 입력 기반 전체 작전 회귀 검증. 실제 렌더링 QA와 구분됩니다.

실행 설정은 `PORT`(기본 3000), `DATA_DIR`(기본 `data`) 환경변수입니다. PowerShell 예: `$env:PORT=3002; npm run dev`. `ROOM_GRACE_MS` 기본값은 60000이며 테스트에서 정리 시간을 줄일 때 사용합니다.

## 로컬 멀티플레이

- 동일 PC: 서로 다른 브라우저 프로필/브라우저 또는 격리된 시크릿 컨텍스트로 접속합니다. **동일 프로필의 탭은 같은 익명 오퍼레이터**입니다. 중복 접속하면 이전 탭을 끊고 새 탭으로 이동합니다.
- 첫 플레이어가 만든 5자리 코드를 나머지 플레이어가 입력합니다.
- 같은 LAN: 한 PC에서 서버를 실행하고 친구들은 `http://서버PC의-LAN-IP:3000`에 접속합니다. Windows 방화벽에서 해당 TCP 포트를 허용해야 합니다. 모든 플레이어는 같은 서버에 접속해야 합니다.
- 방 코드는 그 서버 안에서만 유효합니다. 코드만으로 서로 다른 서버가 연결되지는 않습니다.
- 실행 중 방에는 새 멤버가 들어갈 수 없으며 기존 멤버의 재접속만 허용합니다.
- 연결이 끊겨도 다른 플레이어의 작전은 계속됩니다. 브라우저 새로고침/일시 끊김 후 60초 안에 같은 저장 토큰으로 복귀할 수 있습니다. 분대장 이탈 시 연결된 대원에게 분대장 권한이 넘어갑니다.
- 모두 나간 방은 60초 뒤 정리됩니다. 명시적 **분대 나가기**는 재접속 예약을 제거합니다.

## 인터넷 지원 범위

실제 WebSocket 서버가 있으므로 공용 Node 호스트 또는 포트 전달을 구성한 서버로 원격 플레이할 수 있는 구조입니다. **이번 산출물은 공용 서버에 배포하지 않았으며 서로 다른 실제 인터넷 회선에서 검증하지 않았습니다.** 로컬호스트 검증을 인터넷 검증으로 간주하지 않습니다.

운영 시 Node 서버의 단일 포트를 리버스 프록시로 연결하고 HTTPS/WSS와 WebSocket Upgrade를 지원하세요. 프록시의 유휴 제한은 heartbeat보다 길어야 합니다. `/health`로 상태를 확인할 수 있습니다. 정적 파일 전용 호스팅만으로는 이 게임이 동작하지 않습니다. 로그인·매치메이킹·NAT traversal·대규모 서비스 운영 기능은 없습니다.

## 진행도와 데이터

- 서버 `data/profiles.json`: 크레딧, 무기·개조 해금, 출격·성공·처치 기록, 최근 정산 ID.
- 브라우저 localStorage `doll-token`: 192비트 임의의 익명 프로필 복구 토큰. 토큰은 방 스냅샷에 포함되지 않습니다.
- 저장은 임시 파일 작성 후 rename하며 이전 정상 파일을 `.bak`로 남깁니다. 기본 파일이 손상되면 백업 복구를 시도합니다.
- 서버 재시작 후 진행도는 유지되지만 진행 중인 방과 작전은 메모리 기반이라 복구되지 않습니다.
- 브라우저 저장소를 지우거나 다른 서버로 이동하면 기존 진행도에 자동 연결되지 않습니다. `data/`와 토큰을 함께 보관하세요. 공개 공유 파일에 토큰을 포함하지 마세요.

## 프로젝트 구조

```text
assets/        공식 아리아 PNG와 생성 방향별 래스터 시트
src/art/       PNG 연결·시트 프레임 정의·무기 아이콘
src/client/    로비/HUD, 입력, Canvas 렌더러, Web Audio
src/shared/    타입, 캐릭터·무기·적·개조 데이터, 임무 상수
src/game/      시드 맵, 충돌·시야·A*, 전투·AI·임무 시뮬레이션
src/server/    방 수명주기, WebSocket, 서버 권한, 영속 저장
scripts/       실제 브라우저 QA, 입력 파일럿, 반복 시뮬레이션
tests/        게임·네트워크·저장 테스트
docs/          실제 캡처와 측정 JSON
```

렌더러는 Phaser 대신 Canvas 2D를 사용합니다. 파츠 변형·절차적 이펙트에 필요한 기능만 구현하고 렌더링과 서버 시뮬레이션을 독립시켰습니다. 캐릭터는 실제 이미지 생성 도구로 만든 PNG를 사용하며 원본과 생성 출처를 `assets/README.md`에 기록했습니다. SVG 캐릭터 렌더러는 제거했고 환경·효과·무기 아이콘은 코드로 표현합니다. PNG가 프로젝트에 포함되어 있어 실행 과정에서 이미지 API나 유료 에셋이 필요하지 않습니다.

실제 규칙은 [GAME_DESIGN.md](GAME_DESIGN.md), 검증 수준·측정값·미완성 항목은 [QA.md](QA.md)를 참고하세요.

## 전투 개편과 전후 비교

- AR: 근거리 소총병을 두 발로 처치, 짧은 점사에 적합. SMG: 빠른 연사와 작은 이동 퍼짐. SG: 균등한 10개 산탄, 강한 순간 충격과 근거리 피격 경직.
- 발사 입력 직후 로컬 섬광·반동·소리. 명중·피해·탄약·처치는 계속 서버가 결정하며 확인 이벤트와 중복 연출을 줄입니다.
- 기본 이동 280, 질주 약 398, 정밀 조준 중에도 기본 속도의 82%. 300초 방어를 제거했습니다.
- 4,000×2,700 맵의 12개 산업 모듈, Seed별 구역 종류·내부벽·이동 순서 변경, 경계마다 두 출입구.
- 소총병의 횡이동, 빠른 돌격병, 예고 후 3연발 지원 사수. 적 HP는 기존 65/48/105를 유지했습니다.
