# PROJECT DOLL SQUAD · V4.1 COMBAT SYSTEM REWORK

귀여운 PNG 오퍼레이터가 싸우는 **1–4인 서버 권한형 협동 탑다운 전술 슈터**. V4의 황무지·물리적 증원·경보·Fog·자유 임무·영구 진행도를 유지하며, 무기 선택과 장갑 공략을 개편했습니다.

- **주무장 / 권총 / 소모품**의 세 슬롯. AT는 주무장이므로 AR과 함께 소지할 수 없습니다.
- AP/AV 관통, 일반·내구 피해, 실제 부위 명중과 동력부·무장 파괴.
- 파편·대전차 수류탄, 실제 관측을 차단하는 연막, 의료품과 유한한 팀 보급.
- 움직임을 관측하는 제한된 추적·예측 사격, 시설 경비·제압·측면·요격 역할.
- 적 전멸 없이 발전기 두 기를 공략하고 실제 도착한 수송기로 탈출.

## 실행

Node.js22 이상과 최신 데스크톱 Chrome/Edge를 권장합니다. Windows PowerShell/cmd에서도 기본 명령은 같습니다.

```sh
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000)에 접속합니다. 서버 코드 변경 후에는 개발 명령을 재시작하세요.

```sh
npm run build
npm start
npm test
```

빌드는 타입 검사, 클라이언트 번들, Node 서버를 생성합니다. `npm start`는 빌드 후 실행합니다. 브라우저는 키보드+마우스 PC용이며 별도 계정/로그인은 없습니다.

## 협동 접속

한 명이 분대를 만들고 같은 서버의5자리 방 코드를 공유합니다. 친구는 **같은 서버 주소**에서 코드를 입력합니다. 전원이 준비하면 방장이 Seed·난이도1–10·계약을 정하고 출격합니다. 서로 다른 프로필을 테스트하려면 시크릿 창/별도 브라우저 컨텍스트를 사용하세요. 같은 저장 토큰의 두 탭은 하나의 플레이어로 처리됩니다.

LAN에서는 서버 PC의 방화벽에서 TCP3000을 허용하고 `http://서버의LAN주소:3000`으로 접속합니다. 로컬 방 코드가 인터넷 중계 서버를 만들어 주지는 않습니다. 인터넷 친구와 연결하려면 별도 서버 배포/포트 설정/접근 가능한 주소와 HTTPS/WSS 구성이 필요합니다. 실제 서로 다른 장치의 LAN/WAN·Windows GPU 환경은 이번 자동 QA에서 검증하지 않았습니다.

## 조작

|입력|동작|
|---|---|
|WASD / 마우스|이동 / 독립 조준|
|좌클릭 / 우클릭|사격·사용 / 정밀 조준·예상 투척 범위|
|1 / 2 / 3|주무장 / P-01 / 선택 소모품|
|R / Shift|현재 무기 장전 / 질주(사격 불가)|
|E / F|보급·기밀·탈출·출입구 봉쇄 / 동료 소생|
|Tab / Esc|목표 현황·추적 / 메뉴|

**G 즉시 로켓은 없습니다.** AT는1발 탄창+예비3발이며 별도 권총으로 보병에 대응합니다. 무기마다 탄약이 독립적이고, 전환하면 미완료 장전은 취소됩니다. 장착 시간 중 발사할 수 없습니다. 소모품은 새 클릭당 한 번 사용합니다. 의료품은 만피에서 소비하지 않습니다.

AP보다 AV가 높으면 피해0, 같으면65%, 높으면100%입니다. 밝은 노출 부위를 실제로 맞히세요. 장갑의 후방에 서 있기만 해서는 약점 명중이 아닙니다. 동력부·무장 파손은 이동과 공격을 바꿉니다. 발전기 전면 방호는 우회하거나 대전차 수단으로 깨고, 후방 핵심부는 일반 총기로도 공략할 수 있습니다. 보급 상자는 팀 공용1회이며 소유한 장비의 탄약·선택 소모품만 제한적으로 보충합니다. 아군 오사는 없습니다.

작전 제한은 **30분**이며 HUD에 표시됩니다. 주 목표 후 E로 수송을 요청하면24초 후 실제 수송기가 도착합니다. 연결된 생존자가140거리 안에3초 집결해야 탑승합니다. 적 전멸과 보조 목표는 필요 없습니다. 보조 목표는 통신·출동·보상에 실제 영향을 줍니다.

## 저장과 자료

기본 저장은 `data/profiles.json`, 백업은 `.bak`입니다. `DATA_DIR` 환경변수로 위치를 바꿀 수 있습니다. 서버 저장 디렉터리를 보존해야 진행도가 유지됩니다. 이전 V4 형식1을 읽어 형식2로 안전하게 기록하며 크레딧·해금·전적·정산 기록·선택 주무장을 유지합니다. 구형 전술 발사기 선택 때문에 기존 주무장을 AT로 바꾸지 않습니다.

## QA 재현

```sh
npm test
npm run qa:v41
npx tsx scripts/v41-combat-qa.ts
npx tsx scripts/v41-performance-suite.ts
```

마지막 명령은 Git 이력의 V4 `54709a6`를 별도 `.qa-private-v4-reference` 디렉터리에 추출하고 동일 환경에서 비교합니다. Git 이력과 `tar`가 필요합니다. 브라우저 QA에는 Playwright와 Chromium이 필요하며 `CHROMIUM_PATH`, `QA_OUTPUT`, `QA_PLAYERS`, `QA_SEED`, `QA_DIFFICULTY`로 환경을 지정할 수 있습니다. GUI 브라우저 여러 개와 CPU 실험·전체 테스트를 동시에 실행하면 이2vCPU 환경에서 시간 초과가 발생했으므로 최종 성능/회귀 검사는 분리했습니다.
