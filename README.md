# PROJECT DOLL SQUAD · V3 OPERATIONAL WARZONE

귀여운 PNG 전술 오퍼레이터로 출격하는 **1–4인 서버 권한형 협동 탑다운 슈터**입니다. V2 `014ce837f601`의 전투·캐릭터·무기·방·저장을 보존하고 전장을 다시 구성했습니다. 이제 적 전멸이나 구역 잠금 없이 발전기 두 기를 자유로운 순서로 파괴하고, 적의 순찰·경보·실제 경로 기반 증원에 대응하며 탈출합니다.

![V3 실제 4인 작전](docs/v3/final-four/stage-operate.png)

## 설치와 실행

Node.js 22 이상과 최신 데스크톱 Chrome/Edge를 권장합니다. Windows PowerShell/cmd에서도 같은 기본 명령을 사용합니다.

```sh
npm install
npm run dev
```

**http://localhost:3000** 접속. 한 명이 분대를 만들고 다른 플레이어는 같은 서버에서 5자리 방 코드로 참여합니다. 분대장이 Seed·난이도 1–10·계약을 선택하고, 전원이 준비하면 출격합니다. 서버 코드를 바꾸면 개발 명령을 다시 실행하세요. 클라이언트는 Vite로 갱신됩니다.

```sh
npm run build
npm start
npm test
```

`build`는 TypeScript 검사와 웹/Node 서버 번들을 생성합니다. `start`는 빌드한 `dist/`를 단일 HTTP/WebSocket 포트로 실행합니다. `test`는 전투·시야·100 Seed 경로·AI·증원 연속성·목표·난이도·실제 WebSocket·저장 회귀를 검사합니다. 테스트 서버 포트는 3107입니다. 실행 시 이미지 API나 외부 오디오 서비스가 필요하지 않습니다.

환경변수: `PORT` 기본3000, `DATA_DIR` 기본`data`, `ROOM_GRACE_MS` 기본60000. PowerShell 예: `$env:PORT=3002; npm run dev`.

## BLACKOUT 작전

1. 공유 시야로 정찰합니다. 현재 보이는 지역은 밝게, 탐색했던 지역은 어둡게, 미탐색 지역은 검게 표시됩니다. 벽·대형 컨테이너·닫힌 문 뒤에는 사각지대가 있습니다.
2. **핵심 발전기 A/B를 사격해 파괴**합니다. 순서와 진입 방향은 자유이며 적을 모두 처치할 필요가 없습니다.
3. 선택 목표: 통신탑 파괴로 외부 지원을 늦추고, 전초기지 파괴로 해당 출동지를 무력화하고, E를 유지해 기밀을 회수합니다. 병영도 파괴할 수 있습니다. 출동지 입구에서는 E 3초로 해당 통로를 봉쇄할 수 있습니다.
4. 두 발전기 파괴 후 **탈출 후보 원 안에서 E**로 수송기를 요청합니다. 요청 전까지 선택 목표를 계속 수행할 수 있습니다.
5. 수송기 접근은 24초입니다. **착륙 후 연결된 대원 전원이 반경140 안에 3초간 집결**하면 귀환합니다. 쓰러진 대원은 구조해야 합니다. 수송기는 착륙 65초 후 철수합니다.
6. 결과에서 보상을 받고 재출격합니다. 목표를 끝내도 경보·순찰·증원은 탈출까지 계속됩니다.

통신탑은 이미 행군 중인 병력을 없애지 않습니다. 보이는 출입구의 병력은 실제로 걸어 나오며, 외부 병력은 지도 경계 바깥에서 출발해 진입합니다. 원점·경로 없는 플레이어 근처 생성은 사용하지 않습니다.

## 조작

| 입력                 | 동작                                  |
| -------------------- | ------------------------------------- |
| WASD / 마우스        | 이동 / 독립 조준                      |
| 좌클릭 / 우클릭 유지 | 발사 / 정밀 조준                      |

| R                    | 재장전                                |
| E                    | 보급 / 기밀 / 출입구 봉쇄 / 탈출 요청 |
| F 유지               | 가까운 동료 소생                      |
| Tab 유지             | 분대·목표 현황, 목표를 클릭해 추적    |
| Esc                  | 메뉴, 협동 전장은 계속 진행           |

소총병은 짧은 반응 후 점사합니다. 긴 붉은 예고선은 지원사수에게만 표시됩니다. 벽·엄폐·측면 이동을 사용하세요. 아군 오사는 없습니다. 공격을 받지 않으면 45 HP까지만 회복하며 보급품은 주변 동료도 회복시킵니다.

AR-01과 SMG-02는 기본 제공, SG-03은 220 CR 해금입니다. 초기300 CR로 무기 또는 개조(140 CR)를 구매할 수 있습니다. 구매 후 장비를 선택하세요. 계약 `정찰 보너스`는 같은 BLACKOUT에서 선택 목표 보상만 1.5배로 계산합니다. 캐릭터·총기·성장 트리는 추가하지 않았습니다.

## 멀티플레이 범위

- 동일 PC: 서로 다른 브라우저 프로필 또는 격리된 시크릿 컨텍스트를 사용합니다. 같은 프로필의 탭은 동일 익명 오퍼레이터이며 새 접속이 이전 접속을 대체합니다.
- LAN: 서버 PC를 켜고 친구들이 `http://서버PC의-LAN-IP:3000`에 접속합니다. 서버 PC의 TCP 포트 방화벽 허용이 필요합니다. 방 코드는 같은 서버 안에서만 유효합니다.
- 작전 중 신규 참가 대신 기존 대원의 재접속을 지원합니다. 같은 저장 토큰으로 60초 안에 돌아올 수 있고, 분대장 연결 종료 시 권한이 이전됩니다. 전원이 나간 방은 유예 후 정리됩니다.
- 인터넷: 공용 Node 호스트 또는 포트 전달, HTTPS/WSS 리버스 프록시와 WebSocket Upgrade가 필요합니다. **공용 서버 배포·서로 다른 실제 인터넷 회선·Windows 실기는 검증하지 않았습니다.** 정적 호스팅만으로는 서버가 동작하지 않습니다. `/health`를 제공합니다.

## 저장

서버 `data/profiles.json`에 크레딧·해금·기록·최근 정산 ID를 원자적으로 저장하고 `.bak`로 복구합니다. 브라우저 localStorage `doll-token`이 익명 프로필을 복원합니다. 토큰은 공개 방 스냅샷에 포함되지 않습니다. 서버 재시작 후 진행도는 유지되지만 진행 중 작전은 복구되지 않습니다. 브라우저 저장소를 지우면 해당 익명 프로필에 자동 연결되지 않습니다.

## 재현 가능한 QA

Playwright용 Chromium이 필요합니다. Linux 기본 `/usr/bin/chromium`, 다른 환경에서는 `CHROMIUM_PATH`를 지정하세요.

```sh
npm run build
npm run qa:session
npm run qa:sim
npm run qa:stability
```

- `qa:session`: 빌드 서버와 실제 DOM 입력 브라우저 시험을 함께 실행하고 정리합니다. `QA_PLAYERS=1|2|4`, `QA_SEED`, `QA_DIFFICULTY=1..10`, `QA_STRATEGY=all`, `QA_REVERSE=1`, `QA_PORT` 기본3302, `QA_OUTPUT`, `QA_REPORT_DIR`로 시나리오와 증거 경로를 지정합니다. 기본은 4인·Seed42·난이도3입니다. 쉘별 환경변수 설정 문법은 다릅니다.
- `qa:sim`: 서버에서 필터한 공개 정보와 일반 입력만 쓰는 1·2·4인/세 Seed/선택 목표/실패 회귀입니다. 브라우저 렌더링 검증과 구분합니다.
- `qa:stability`: 40회 작전과 GC 후 메모리·틱 비용·상한을 기록합니다.
- `qa:render`, `qa:audio`: 실행 중인 **개발 서버**에서 합성 4인+적20명+Fog 렌더 부하 및 실제 AudioEngine WAV를 측정합니다. `QA_URL`로 서버를 지정합니다.
- `QA_SCRIPT=scripts/source-browser-qa.ts npm run qa:session`: 실제 출동지 관찰·영상. 서버 전용 출동/이동 감사 자료는 `QA_TRACE_FILE`을 명시한 진단 실행에서만 기록하고 플레이어에게 전송하지 않습니다.
